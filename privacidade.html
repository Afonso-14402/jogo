Resumo

O jogo não recolhe dados pessoais. Não há contas, anúncios, compras nem estatísticas de utilização.

O que fica no teu aparelho

  • O jogo guarda no teu telemóvel (ou no browser) o progresso, as almas, a coleção, as conquistas e as opções.
  • Estes dados não saem do aparelho. Apagam-se quando desinstalas a app ou limpas os dados do browser.
  • O código de Transferir progresso só é criado quando tu o pedes, e és tu que o copias para outro aparelho.

Jogar a 2

  • Só quando usas Jogar a 2 é que o jogo usa a internet: os dois telemóveis ligam-se diretamente um ao outro (WebRTC).
  • Para se encontrarem, usam o servidor gratuito PeerJS e, se for preciso, servidores de ligação (STUN/TURN). Estes servidores veem o endereço IP de cada telemóvel apenas para fazer a ligação.
  • O jogo não envia o teu nome, email, localização ou contactos. O código da sala é aleatório e deixa de existir quando a sala fecha.
  • Durante o jogo a 2, só o estado do jogo (posições, vida, itens) passa entre os dois telemóveis.

Permissões da app Android

  • Internet: só para o modo Jogar a 2.
  • Vibração: o telemóvel vibra quando levas dano (dá para desligar nas Opções).

Contacto

Dúvidas ou pedidos: abre uma questão em github.com/afonso-14402/jogo/issues.

Summary

The game does not collect personal data. There are no accounts, ads, purchases or usage analytics.

What stays on your device

  • The game stores your progress, souls, collection, achievements and options on your phone (or in your browser).
  • This data never leaves your device. It is deleted when you uninstall the app or clear your browser data.
  • The Transfer progress code is only created when you ask for it, and you copy it to another device yourself.

2-Player Co-op

  • The game only uses the internet when you play 2-Player Co-op: the two phones connect directly to each other (WebRTC).
  • To find each other they use the free PeerJS server and, when needed, connection servers (STUN/TURN). These servers see each phone's IP address only to make the connection.
  • The game does not send your name, email, location or contacts. The room code is random and stops existing when the room closes.
  • During co-op, only the game state (positions, health, items) is exchanged between the two phones.

Android app permissions

  • Internet: only for 2-Player Co-op.
  • Vibration: the phone vibrates when you take damage (can be turned off in Options).
